
# pbrAudioCommon
## [v0.3.0] - 2026-11-04

### Added
- Added bz2 compression and decompression support for classes saved by the `KleptoEntityStore` class in `pbrAudioCommon`.
- Introduced `pbrAudioDAW` featuring a new Terminal User Interface (TUI).
- Integrated the Viewport Panel and new 3D viewport widgets GUI into `pbrAudioBlender`.
- Added new mono modal displacement to acoustic pressure processors, modal displacement processors, and audio forces processors in `pbrAudioSignals`.
- Added new methods in the `StorageEngine` class to edit metadata on the backend.
- Added `SynthPostProcess` and rigidBody postProcess classes to describe audio data processing chains and rigidBodySynth post-processing in `pbrAudioStorage` metadata.
- Added Blosc2 support to handle large NumPy arrays in `ScoreEvent` within `pbrAudioShaders`.

### Changed
- Switched `blosc2Backend` to parallel append and mmapped mode in `pbrAudioStorage`.
- Handled `track_group` in `pbrAudioSignals` to subdivide processors based on DAG node/edge goals.
- Performed a complete code rewrite of `pbrAudioStorage` and aligned postProcess classes with new storage and signal features.

### Fixed
- Fixed typos, syntax errors, and missing definitions across `KleptoEntityStore`, `StorageEngine`, `Blosc2Backend`, `pbrAudioShaders`, `pbrAudioSignals`, and `pbrAudioBlender`.
- Fixed misalignment issues between signals and `ScoreEvent` originating from `physicsSolver` and `rigidBody`.
- Prevented Out Of Memory (OOM) errors in `ModalComposer` within `rigidBody`.
- Fixed storage `root_path` and `enable_proxy_synth` indentation in `pbrAudioBlender`.

# pbrAudioCommon
## [v0.3.0] - 2026-11-05

### Added
- Introduced `pbrAudioDAW` featuring a new Text User Interface (TUI).
- Integrated Viewport Panel and 3D viewport widgets into `pbrAudioBlender`.
- Added new signal processors to `pbrAudioSignals`:
    - Mono modal displacement to acoustic pressure processors.
    - Modal displacement and audio forces processors.
    - Logic to handle `track_group` for processor subdivision based on DAG node/edge goals.
- Added new features to `pbrAudioStorage`:
    - New methods in `StorageEngine` for editing backend metadata.
    - New `postProcess` and `SynthPostProcess` classes for describing synthesis processing chains in metadata.
- Implemented bz2 compression/decompression for classes stored via `KleptoEntityStore` in `pbrAudioCommon`.

### Changed
- Refactored `rigidBody` and `physicsSolver` post-processing classes for alignment with new storage and signal features.
- Optimized `pbrAudioStorage` by switching to parallel append and mmapped mode for the `Blosc2Backend` class.
- Completely refactored `pbrAudioStorage` codebase.
- Updated `StorageEngine` to include `_get_props()` for loading custom `AudioDataType` configurations.

### Fixed
- Resolved multiple "Out of Memory" (OOM) errors in `ModalComposer` (rigidBody).
- Fixed misalignment issues between signals and `ScoreEvent` generated by `physicsSolver` and `rigidBody`.
- Fixed numerous typos and syntax errors across `pbrAudioStorage`, `pbrAudioSignals`, `pbrAudioBlender`, and `KleptoEntityStore`.
- Corrected storage `root_path` in Blender export classes.
- Fixed `ModuleNotFoundError` related to `zarr` and `blosc2` backends.
- Fixed variable naming conventions in post-processing modules.
